## 512MB 内存到底能干什么

WePC 把这条巴西线路定位成 TikTok 运营节点，配置和这个定位是匹配的。TikTok 账号环境的主力在手机、模拟器或指纹浏览器上，VPS 承担的是网络出口和轻量中转，1 核 512MB 够跑。你要在这台机器上再装数据库、面板、采集程序，内存会先撑不住。

判断标准很简单：这台机器上要不要同时跑三个以上常驻服务。要，就加钱买本地机房的 2GB 起步套餐；不要，512MB 够用，省下的钱可以多开一个节点做备用。

## 退款、库存、客服：三个下单前该知道的限制

退款窗口是 3 天，且流量使用不超过 10GB。满足条件可以全额退到账户余额，或者扣每笔 10 元手续费原路退回；超过时间或流量，只能按比例退到余额，余额不可提现。
